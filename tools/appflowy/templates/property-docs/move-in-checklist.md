# Move-In Checklist

Use for every new lease at Woodland Parc Townhomes and Riverwood Club
Apartments. Georgia note: if a security deposit is taken, O.C.G.A. § 44-7-33
requires giving the resident a written list of existing damage **before**
collecting the deposit — this walkthrough produces that list. (Process doc,
not legal advice.)

## Before the resident arrives

- [ ] Unit cleaned; carpets shampooed or floors mopped
- [ ] All keys, fobs, mailbox keys and gate/pool cards cut and tested
- [ ] Smoke detectors present and tested on every level and outside sleeping areas; CO detector if gas appliances
- [ ] HVAC filter replaced; system heats and cools
- [ ] Water heater, all faucets, toilets and drains checked — no leaks
- [ ] Appliances run through a cycle (range, fridge, dishwasher, disposal, washer/dryer if provided)
- [ ] GFCI outlets tested (kitchen, baths); all light fixtures working
- [ ] Windows open, close and lock; blinds intact
- [ ] Pest treatment done if the unit sat vacant

## Walkthrough with the resident (document everything)

- [ ] Photograph every room, inside cabinets, and appliance interiors — file in Photo Vault under the unit
- [ ] Complete the move-in condition form room by room; note ALL existing damage, however small
- [ ] Both parties sign and date the condition form; give the resident a copy (this is the § 44-7-33 list)
- [ ] Record utility meter readings (electric, gas, water) and confirm accounts transferred

## Paperwork and handoff

- [ ] Lease signed by all adult occupants (use E-Sign); deposit and prorated rent collected before keys
- [ ] Deposit placed in the escrow account and the resident informed where it is held
- [ ] Renter's insurance certificate on file (if required by the lease)
- [ ] Resident given: emergency maintenance number, portal login, trash/parking rules, mailbox location
- [ ] Lease dates entered in the lease tracker; renewal reminder set for 90 days before lease end
